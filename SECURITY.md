# Политика безопасности

## Сообщение об уязвимости

Не публикуй рабочие SOCKS5-логины, пароли, токены или персональные журналы в Issues.

Для уязвимости используй приватный Security Advisory репозитория GitHub. В сообщении укажи версию Windows, версию geminUp, шаги воспроизведения и обезличенный фрагмент журнала.

## Границы защиты

geminUp предотвращает прямой fallback только для hostname, перечисленных в `transport/domains.txt`, пока локальный transport работает. Приложения, которые игнорируют системный proxy, не входят в модель защиты.

SOCKS5 endpoint видит целевые hostname и сетевые соединения. Используй только доверенный прокси.

Конфигурация шифруется DPAPI `LocalMachine` и дополнительно защищается ACL. Локальный администратор или `SYSTEM` всё равно может получить доступ к данным — это нормальная граница безопасности Windows, а не защита от администратора компьютера.
